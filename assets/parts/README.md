# Local PC Part Photos

Upload your own photos into the matching folder. No online image search is used by the gallery.

Supported folder mapping:
- `processor/` — AMD Ryzen 5 7500F
- `graphics-card/` — MSI RTX 3060 12GB
- `ram/` — 16GB DDR5 6000MHz
- `motherboard/` — ASUS Prime B650M-A II
- `cpu-cooler/` — DeepCool AK500
- `monitor/` — ASUS VY249HGR 120Hz
- `pc-case/` — PC Power Ice Cube V2
- `headset/` — Rapoo VH360 7.1

## Naming your images

Inside each part folder, name photos exactly `image-1.jpg`, `image-2.jpg`, ... up to `image-8.jpg`.

Example:

```text
assets/parts/graphics-card/image-1.jpg
assets/parts/graphics-card/image-2.jpg
```

Use JPG/JPEG files and keep the exact lowercase filenames. You can add between 1 and 8 photos per component. If a folder has no photos yet, the gallery shows the folder path so you know where to upload them.
